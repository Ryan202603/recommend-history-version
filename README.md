## 🤝 贡献指南

欢迎通过 Pull Request 添加你心中的经典 App！

1. Fork 本仓库
2. 在下方表格中新增一行（GitHub Pages 会自动解析展示）
3. 提交 PR

### 表格格式说明

在 `| 应用名称 | 分类 | 平台 | 评分 | 简介 | 链接 |` 表格中新增一行，链接单元格支持以下标记：

| 标记            | 含义          | 示例              |
| :-------------- | :------------ | :---------------- |
| 链接末尾加 `⛔` | 表示已停运    | `[详情](url)⛔`   |
| 链接末尾加 `⭐` | 表示特别推荐  | `[详情](url)⭐`   |
| 两者可组合      | 已停运 + 推荐 | `[详情](url)⛔⭐` |

**评分规则**：每颗 ★ 代表 1 分，½ 表示 0.5 分。例如 `★★★★½` = 4.5 分。

**平台列**：用逗号分隔，支持 `android` / `ios` / `windows` / `mac` / `linux` / `web`，或使用 `全平台` 自动展开。

**示例行**：

```
| Foo App | 工具 | android, ios | ★★★★½ | 一段简短的描述 | [详情](https://example.com)⭐ |
```

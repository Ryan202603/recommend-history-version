## 🤝 贡献指南

欢迎通过 Pull Request 添加你心中的经典 App！

1. Fork 本仓库
2. 在下方表格中新增一行（GitHub Pages 会自动解析展示）
3. 提交 PR

### 表格格式说明

表格共三列：`应用名称 | 版本 | 简介`

- **应用名称**：末尾可加标记
  - `⛔` — 表示已停运
  - `⭐` — 表示特别推荐
  - 可组合使用，如 `Foo App⛔⭐`
- **版本**：填写具体版本号，如 `1.0`、`2012`、`7.x`；仅一个版本用 `—`
- **简介**：该版本的特点或描述

**一个应用可以对应多行**（不同版本/特点），相同名称会自动合并展示。

**示例行**：

```
| Foo App⭐ | 2.0 | 新增离线模式和多语言支持 |
| Foo App⭐ | 3.0 | UI 全面重构，性能大幅提升 |
```
